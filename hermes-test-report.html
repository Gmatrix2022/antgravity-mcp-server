原因
Hermes 容器未安装 mcp Python 包（pip show mcp 无输出），无法通过 native MCP client 调用工具。
根本原因：FastMCP 的 streamable-http 传输层需要正确的 HTTP session 握手（先 GET 获取 session ID，再 POST 带 session ID），curl 无法正确处理带有 Host: localhost:9000 请求头约束的 FastMCP session 流程，导致所有工具调用返回 Missing session ID 或 421 Misdirected Request (Invalid Host header)。/health 端点独立于 MCP session 机制，所以可用。

结论与修复方案
问题定位：不是 MCP 服务器的问题，是 Hermes 容器端缺少 mcp Python 包，无法解析 FastMCP 的 streamable-http session 握手。Hermes 的 native MCP client 依赖 import mcp，但包未安装，所以 tools 显示为 0，连接状态 false。
修复方案 A（推荐）：在 Hermes 容器内安装 mcp 包：
docker exec hermes pip install mcp
或在容器内：pip install mcp
安装后重启 Hermes Gateway，MCP 工具即可正常注册和调用。
修复方案 B：让 AntGravity 方在 server.py 中为 /mcp 端点添加一个独立的健康检查路由（类似 /health），绕过 session 握手直接返回服务器就绪状态。
