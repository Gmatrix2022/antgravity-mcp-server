二、为什么不是 Windows MCP / ACP / CLI

方式适合什么这里的问题结论
Windows MCP桌面、鼠标、文件、窗口不是 AntGravity 专用能力层不够
ACPIDE 与本地 agent 进程 stdio 通讯跨主机要 SSH 桥，复杂不优先
CLI/PowerShell一次性脚本和构建无工具发现、无 schema、状态弱备用
MCP HTTP跨主机工具调用需要新建 server主方案
